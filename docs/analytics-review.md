# Еженедельный ревью-ритуал аналитики портфолио

> REQ-039. 15 минут, раз в неделю (понедельник утром). Замыкает петлю «аналитика → оптимизация»: сайт не «сломан» — он должен управляться данными.

## 1. Открыть дашборд «Рекрутер»

[Дашборд «Рекрутер»](https://us.posthog.com/project/451732/dashboard/1994322) — 3 тайла: «Откуда пришли», «Топ страниц», «Funnel: рекрутер → контакт».

## 2. Фаннел «рекрутер → контакт»

Шаги: **главная → /projects/ → контакт** (CV / Telegram / LinkedIn / GitHub — GroupNode OR).

Смотреть:
- **Конверсия главная → контакт** — базовая ~6% на 30 дней. Падение ниже 5% → проверить CTA и /projects/.
- **Где отваливаются** — главная → /projects/ теряет ~70% (это нормально: часть визитов — боты/случайные). Важен тренд, не абсолют.
- **Медиана времени до контакта** — ~5 мин от /projects/. Если растёт — контент стал хуже вести к контакту.

> Примечание: шаг `/demos/` удалён из фаннела 2026-09-08 — страницы не существует (демо встроены в карточки проектов, games живёт на `/games/`). Не возвращать.

## 3. Топ страниц и реферры

- **Топ страниц** — какие проекты/посты смотрят. Если какой-то проект стабильно в топе, но не ведёт к контакту — усилить его CTA.
- **Реферры** (база 2026-09-08, 30 дней):
  - `nikitaboyarkin.github.io` — self-referral (внутренняя навигация), доминирует.
  - `github.com` — **главный внешний источник** (~70 pv/30д). Ссылка в GitHub-профиле работает.
  - `$direct` — ~80 pv/30д.
  - `www.linkedin.com` — **почти ноль** (4 pv за 30д). Если LinkedIn-профиль ссылается на сайт — проверить, насколько ссылка заметна.
  - `www.google.com` — ~0. Органика не ожидается для портфолио, но следить.
- **UTM** (REQ-038): `utm_source`/`utm_medium`/`utm_campaign` захватываются на `$pageview` автоматически. Единственный источник — `utm_source=github` (~1–11 pv/день). Остальной трафик без UTM — нормально для портфолио.
